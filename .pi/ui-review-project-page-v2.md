### Issues found

**Primary question — the new Contacts row**
- **🟠 Icons are guessable but not self-explanatory.** The envelope is universally read as e-mail; the green ORCID "iD" mark is recognisable to researchers, but as a *link* it has no visible affordance (no underline, no chevron, no label) — a lab scientist who has never seen an ORCID iD will read it as decoration or a status dot, in part because the *other* green on this page means "step complete" in the progress rail. Hover/focus disclosure is fine as a fallback, not as the only cue.
- **🟠 (b) "Wow Cool" grey person glyph reads as an avatar, not "no ORCID".** A grey human silhouette in the slot where colleagues show the green ORCID mark looks like a profile-photo placeholder / "anonymous user" — nothing signals *absence of a recording*. Safer: drop the slot entirely for contacts without an ORCID, or show a dimmed ORCID mark with a struck/"not set" treatment plus a tooltip. Note also the three chips then have unequal internal rhythm (2 icons vs 3 slots), which is what makes the placeholder look like content.
- **🟠 (c) The row is buried.** Contacts sits *after* a 3-line truncated abstract and the "Show more" link, i.e. furthest from the title, while a large empty area under "Add experiment / Export summary" in the hero's right column stays unused. Who owns the project is higher-value scannable metadata than prose; it should move up beside the title/meta block (or into that right-hand whitespace) rather than adding a whole extra band above the rule.
- **🟡 (d) Cramped / small targets.** Chips are ~32–34px tall with the role tag, name and two ~14–16px icons tightly packed; the icon links are well under a comfortable 44px target and sit adjacent to each other, so mis-taps between ORCID and e-mail are likely. Pad the chip and give the icons breathing room + focus rings.
- **🟡 Role codes PI/PM/PR are unexplained** and "PR" is ambiguous (public relations? reviewer?); no legend and no tooltip is visible.

**New in this capture**
- 🟡 **Safety signal repeated four times** for the same fact: hero pill "2 experiments need attention", rail node 3 amber, per-card "Needs attention" badges, and the panel rows. Repetition dilutes rather than reinforces.
- 🟡 **Redundant navigation per card:** each card has header buttons "Samples"/"Dataset" *and* per-panel "Open" links pointing at the same target; "Open" vs "Open dataset" is also two different labels for one concept.
- 🟡 **Ellipsis splits a word:** the description ends "using mass-…" — a hyphen-adjacent cut reads as breakage; truncate on a word boundary.
- 🟡 **Empty state doubles up:** the "Smoke test edit immunopeptidomics" panels print "Nothing registered yet" *and* "No samples to show yet" / "No measurements to show yet" in the same box, and the zero-stat strip shows a bare "0 0 0 0".
- 🔵 "Smoke test edit immunopeptidomics" is still rendered with full-card weight as a peer of real experiments — it reads as leftover test data, and its "Genomics" tag contradicts the project's "Primary data type: Immunopeptidomics" in Project details.
- 🔵 Breadcrumb "Projects / Q2IMMU Immunotest" mixes code-first naming while the title is name-first with the code as a suffix.

### What to look into
- Hover/focus behaviour of the two icon links: is there a real tooltip (`title`/`aria-label`), a visible focus ring, and does the ORCID link go to `orcid.org/0000-…` while the envelope opens a mail client? Also keyboard tab order through the chip row.
- Whether the "no ORCID" case can be toggled/edited anywhere from the page — no visible "edit contacts" affordance.
- Contrast values for the grey meta text, the "Q2IMMU" code, amber-on-cream links, and the purple "Proteomics" chip (AA pass/fail).
- Rail semantics: what does a node with no content mean, and can the four nodes be made tick-or-number consistently with a legend?
- Narrower viewport: does the contacts chip row wrap gracefully, and do the hero's left column and the right-aligned buttons collide?

### Overall impression
The structure is sound and has clearly improved — the rail + "Needs attention" panel + experiment cards now tell a coherent "where does this project stand" story, and removing raw ORCID/e-mail strings from the Contacts row is the right instinct for clutter. The change as executed is only half-done: the icons carry all the meaning but none of the affordance, and the "no ORCID" placeholder actively miscommunicates as an avatar. Highest-impact single improvement: move the Contacts row up into the hero next to the title/meta and give the icons real affordance (label/tooltip + larger targets), replacing the grey person glyph with a clear "no ORCID recorded" treatment — and while there, delete the duplicated "Add experiment" in the Experiments header so a page about fixing missing data has one obvious primary action.
